# RIGP · Expediente de evidencia

## Objetivo

El expediente de evidencia transforma un hallazgo priorizado en una pauta de revisión comprensible y accionable. No reemplaza la fuente, los documentos primarios ni la evaluación jurídica.

La experiencia debe responder en este orden:

1. **Qué pasó**: relación servicio → proveedor, periodo, magnitud y familia de hallazgo.
2. **Por qué conviene mirarlo**: prioridad de revisión, señales y convergencia.
3. **Qué evidencia existe**: capas disponibles y contexto externo candidato.
4. **Qué falta verificar**: documentos, competencia, ejecución, vínculos o recurrencia según el tipo de hallazgo.
5. **Qué hacer después**: ruta breve de tres pasos y acceso directo a la validación humana.

## Principio de diseño

El expediente no debe obligar al analista a interpretar primero códigos técnicos ni recorrer múltiples gráficos. La lectura ejecutiva antecede al detalle. Las señales técnicas se mantienen como trazabilidad y no como lenguaje principal.

## Cadena de evidencia

Cada expediente presenta cinco capas con estado explícito:

- Hecho presupuestario.
- Patrones analíticos.
- Contratación y documentos.
- Contexto externo.
- Red y recurrencia.

Los estados de capa significan **disponible**, **por verificar** o **contexto**. No significan probado/no probado ni regular/irregular.

## Integridad pública

Sólo cuando existe convergencia suficiente, RIGP puede sugerir que corresponde verificar intervención de funcionarios, vínculos, decisiones de adjudicación o eventuales beneficios indebidos. Esta sugerencia es una ruta de revisión, no una atribución de delito o responsabilidad.

Secuencia obligatoria:

`HALLAZGO -> EVIDENCIA -> DOCUMENTOS -> VÍNCULOS/CONTEXTO -> HECHOS CONFIRMADOS -> EVALUACIÓN ESPECIALIZADA`

Nunca:

`HALLAZGO -> DELITO`

## Integración con el piloto

El botón **Abrir expediente** reemplaza la lógica de “ver sustento”. Desde el expediente el analista puede:

- aplicar la relación al tablero para explorar contexto;
- ir directamente a la validación humana;
- copiar una pauta de revisión para trabajo documental;
- volver al tablero sin perder el contexto de servicio y proveedor.

El expediente debe mantenerse compacto, con información crítica antes del primer scroll y con diseño responsive.
